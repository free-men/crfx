# 🚗 CARFAX REPORT CLIENT PORTAL

Сучасний, адаптивний веб-сайт для ваших клієнтів, який можна безкоштовно розмістити на **GitHub Pages** або будь-якому статичному хостингу.

Сайт надає зручний інтерфейс для:
1. **Введення API-ключа** (з можливістю збереження в браузері та перевіркою валідності).
2. **Введення 17-значного VIN-номера** автомобіля (з автоматичною перевіркою стандарту ISO 3779, забороною літер I, O, Q та лічильником символів).
3. **Вибору мови звіту** (🇺🇦 Українська, 🇬🇧 English, 🇵🇱 Polski, 🇷🇴 Română, 🌐 Русский).
4. **Перевірки статистики та лімітів по API-ключу** в реальному часі (загальний баланс звітів, денний ліміт, залишок на сьогодні, всього згенеровано, прогрес-бар квоти).
5. **Генерації та миттєвого завантаження чистого PDF звіту Carfax**.

---

## 🚀 Як розмістити сайт на GitHub Pages (за 2 хвилини)

Цей сайт повністю статичний (HTML5, CSS3, Vanilla JavaScript) і **не потребує** жодного бекенд-хостингу чи збірки `npm`.

### Спосіб 1: Через веб-сайт GitHub (Найпростіший)

1. Зайдіть на [GitHub.com](https://github.com) та створіть новий публічний репозиторій (наприклад, `carfax-portal`).
2. Відкрийте репозиторій та перетягніть (Drag & Drop) у вікно браузера всі файли з цієї папки `carfax-web-portal`:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `config.js`
   - `favicon.svg`
   - `.nojekyll`
3. Натисніть кнопку **Commit changes** (Зберегти зміни).
4. Перейдіть у вкладку **Settings** (Налаштування репозиторію) ➔ розділ **Pages** (ліве меню).
5. У блоці **Build and deployment**:
   - **Source:** Оберіть `Deploy from a branch`
   - **Branch:** Оберіть `main` (або `master`) та папку `/ (root)`
   - Натисніть **Save**.
6. Через 30-60 секунд GitHub створить посилання на ваш сайт:
   `https://ВАШ_ЛОГІН.github.io/carfax-portal/`
   
Це посилання ви можете надавати будь-яким своїм клієнтам!

## ⚙️ Налаштування адреси вашого API сервера

У файлі [`config.js`](config.js) вкажіть зовнішню адресу вашого сервера:

```javascript
window.APP_CONFIG = {
    // Адреса вашого запущеного сервісу CarfaxChecker (порт 5000)
    API_SERVER_URL: "http://209.50.240.101:5000",
    
    // Мова за замовчуванням
    DEFAULT_LANGUAGE: "uk",
    
    // Автоматично завантажувати згенерований PDF
    AUTO_DOWNLOAD_PDF: true
};
```

Адреса сервера централізовано задається у цьому файлі, тому клієнти не мають доступу до зміни системних налаштувань.

## 🔒 Важливе зауваження: HTTPS (GitHub Pages) та HTTP API (Mixed Content)

GitHub Pages працює виключно за захищеним протоколом `https://`. Якщо ваш сервер `CarfaxChecker` використовує незахищену IP-адресу `http://209.50.240.101:5000`, браузери клієнтів (Chrome, Edge, Safari) з міркувань безпеки можуть блокувати прямі HTTP-запити (*Mixed Content*).

### Як зробити роботу сайту 100% безперебійною:

#### Варіант А (Рекомендований): Безкоштовний Cloudflare Tunnel (HTTPS)
1. Встановіть на сервер безкоштовну утиліту Cloudflare:
   ```bash
   winget install Cloudflare.cloudflared
   ```
2. Запустіть тунель однією командою:
   ```bash
   cloudflared tunnel --url http://localhost:5000
   ```
3. Ви отримаєте безкоштовну безпечну HTTPS адресу (наприклад, `https://carfax-bot-abc12.trycloudflare.com`).
4. Впишіть цю адресу в [`config.js`](config.js) — після цього сайт на GitHub Pages працюватиме ідеально у всіх браузерах без будь-яких попереджень!

#### Варіант Б: Дозволити в браузері (Для швидкого тесту)
Якщо клієнт відкриває сайт і бачить помилку підключення:
1. Клієнт натискає на іконку ліворуч від адресного рядка в браузері (замочок або повзунки).
2. Обирає **«Налаштування сайту» (Site settings)**.
3. Знаходить рядок **«Небезпечний вміст» (Insecure content)** та перемикає на **«Дозволити» (Allow)**.
4. Оновлює сторінку.

## 📋 Що бачить клієнт на сайті

1. **Поле API-ключа**:
   - Можливість приховати або показати символи ключа (👁️).
   - Чекбокс «Запам'ятати ключ у цьому браузері».
   - Кнопка «🔍 Перевірити ліміти».
2. **Панель статистики та лімітів**:
   - Залишок загального балансу (кількість звітів).
   - Денний ліміт та скільки звітів доступно саме сьогодні.
   - Кількість згенерованих звітів сьогодні та за весь час.
   - Візуальний прогрес-бар використання квоти.
   - Статус ключа (Активний / Залишилось мало / Ліміт вичерпано).
3. **Поле VIN-коду**:
   - Автоматичне форматування великими літерами.
   - Захист від помилкових літер `I`, `O`, `Q`.
   - Індикатор `17 / 17` символів.
   - Кнопка швидкої вставки з буфера обміну.
4. **Вибір мови**:
   - 🇺🇦 Українська (uk)
   - 🇬🇧 English (en)
   - 🇵🇱 Polski (pl)
   - 🇷🇴 Română (ro)
   - 🌐 Русский (ru)
5. **Генерація PDF**:
   - Інтерактивний покроковий індикатор (Авторизація ➔ Пошук ➔ Переклад ➔ PDF рендеринг).
   - Автоматичне завантаження готового файлу `Carfax_{VIN}.pdf`.
   - Кнопка попереднього перегляду прямо у браузері.
   - Автоматичне оновлення лімітів після кожної успішної генерації.
